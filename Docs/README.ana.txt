                              Large General Encyclopedia DZS
                                        DZS-lex 1.0

               Citation, documentation, download, and licence available from
                             http://hdl.handle.net/11356/2332

This directory contains the linguistically annotated DZS-lex 1.0 encyclopedia.
The DZS-lex TEI document was first conveted to plain text (each entry / sense in a new line),
and then annotated with the CLASSLA pipeline (https://github.com/clarinsi/classla) and the resultant
CoNLL-U file enhanced with basic entry-leven metadata. This file was then converted to vertical
encoding for CQP-based concordancers.

This directory contains the following files:

- DZS-lex.conllu: DZS-lex in CoNLL-U with basic entry metadata
- DZS-lex.vert: DZS-lex as a vertical file
- dzslex.regi:  Registry file as used for the CLARIN.SI noSketch Engine installation
