                              Large General Encyclopedia DZS
                                        DZS-lex 1.0

               Citation, documentation, download, and licence available from
                             http://hdl.handle.net/11356/2332

This directory contains the source of the TEI-encoded DZS-lex 1.0 encyclopedia.
This source was used in production of the CD-ROM with the encyclopeda.
This directory contains the following files:

- DZS-lex.front.pdf: Front matter from the "Dnevenik" edition of the encyclopedia
- KNAUR.648: XML-like, CP1250 source file; special characters outside the CP1250 range
  are encoded in a dedicated descriptive encoding
- KNAUR.xml: The source file converted to XML and special chars (where possible) converted
  to Unicode
- DZS-lex.chars.tsv: Mapping table between special chacters and Unicode eqivalents
