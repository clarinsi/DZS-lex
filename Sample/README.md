# Samples of DZS-Lex, i.e. "Veliki splošni leksikon DZS"

This directory gives a sample of the complete DZS-Lex, which is availabe at the CLARIN.SI repository.

Files in this directory:

1. DZS-lex.front.pdf: Introductory matter (title page, imprint, contributors, explanations)
2. KNAUR-sample.xml: Sample of the source entries
3. DZS-lex-sample.tei.xml: Source converted to TEI, all in one file; or
   1.  DZS-lex-sample.xml: Root XML/TEI with teiHeader; XIncludes:
   2.  DZS-lex.front.xml: Introductory matter
   3. DZS-lex-sample.body.xml: Entries 
4. DZS-lex-sample.conllu: CLASSLA UD annotated text of the entries, each entry has basic metadata attributes
5. DZS-lex-sample.vert: Vertical file for CQP-type concordancers, generated from CoNLL-U
   1. DZS-lex.registry: Registry file form noSketch Engine @ CLARIN.SI
